# Revolution Clo Style Landing Page Clone

This project is a responsive static landing page inspired by the structure and style of revolutionclo.com.

## Run locally

From this folder, run:

```bash
python -m http.server 3000
```

Then open:

```text
http://localhost:3000
```

## Files

- `index.html` — page structure
- `styles.css` — styling and layout
- `script.js` — mobile navigation and FAQ behavior
